# 华法林钠片说明书

> **通用名**：华法林钠片
> **英文名**：Warfarin Sodium Tablets
> **ATC编码**：B01AA03
> **文档类型**：药品说明书综合整理

---

## 【药品名称】

- **通用名**：华法林钠片
- **商品名**：Coumadin（原研）
- **化学名**：4-羟基-3-(3-氧代-1-苯丁基)-2H-1-苯并吡喃-2-酮钠盐
- **分子式**：C₁₉H₁₅NaO₄
- **分子量**：330.31

---

## 【成份】

- **主要成份**：华法林钠

---

## 【适应症】

1. **预防和治疗血栓栓塞性疾病**
   - 深静脉血栓形成（DVT）
   - 肺栓塞（PE）
2. **心房颤动**患者的脑卒中预防
3. **心脏瓣膜置换术后**的抗凝治疗
   - 机械瓣：终身抗凝，目标INR 2.5-3.5
   - 生物瓣：术后3-6个月抗凝
4. **心肌梗死后**的抗栓治疗
5. **短暂性脑缺血发作（TIA）**的二级预防

## 【用法用量】

### 剂量个体化原则
- **华法林剂量必须个体化**，根据INR调整
- 不同患者维持剂量差异极大（1-10mg/日）
- 建议起始低剂量，根据INR逐步调整

### 成人起始方案

| 情况 | 起始剂量 | 说明 |
|------|---------|------|
| 一般成人 | 3-5mg/日 | 根据年龄/体重调整 |
| 老年人 | 2-3mg/日 | 从低剂量开始 |
| 低体重 | 2-3mg/日 | — |
| 肝功能不全 | 1-2mg/日 | 减量起始 |
| CYP2C9基因多态性 | 需基因检测指导 | *2/*3等位基因携带者需减量 |

### INR监测与调整

| 时间 | 监测频率 |
|------|---------|
| 起始阶段 | 每日或隔日监测INR |
| 剂量调整期 | 每2-3天 |
| 稳定期 | 每4周（最长不超过12周） |

### INR目标范围

| 适应证 | 目标INR |
|--------|---------|
| 房颤（非瓣膜性） | 2.0-3.0 |
| DVT/PE治疗 | 2.0-3.0 |
| DVT/PE预防 | 2.0-3.0 |
| 生物瓣置换 | 2.0-3.0 |
| **机械瓣置换（二尖瓣）** | **2.5-3.5** |
| 机械瓣置换（主动脉瓣） | 2.0-3.0 |
| 心梗后抗栓 | 2.0-3.0 |

### INR异常处理

| INR值 | 处理方案 |
|-------|---------|
| 略高于目标（<5.0） | 减少剂量或暂停1次 |
| 5.0-9.0，无出血 | 暂停1-2次，口服维生素K 1-2.5mg |
| >9.0，无出血 | 暂停，口服维生素K 2.5-5mg |
| 任何INR，严重出血 | 暂停 + 静脉注射维生素K 5-10mg + 凝血酶原复合物(PPC)或新鲜冰冻血浆(FFP) |

## 【不良反应】

### 最常见
- **出血**（最重要不良反应）
  - 轻度：瘀斑、鼻出血、牙龈出血、月经过多
  - 中度：消化道出血、血尿
  - 重度：颅内出血、腹膜后出血、致命性出血

### 其他不良反应
| 系统 | 不良反应 | 发生率 |
|------|---------|--------|
| 皮肤 | **皮肤坏死**（华法林诱导） | 罕见，多发生于起始数日 |
| 皮肤 | 紫趾综合征（胆固醇结晶栓塞） | 罕见 |
| 消化 | 恶心、呕吐、腹泻 | 少见 |
| 肝脏 | 肝毒性（肝酶升高） | 罕见 |
| 其他 | 脱发、血管炎 | 极罕见 |

---

## 【禁忌症】

1. **活动性出血**（消化道出血、颅内出血等）
2. **严重肝功能不全**（凝血因子合成减少）
3. **严重肾功能不全**
4. **近期（6周内）颅内/脊柱/眼科手术**
5. **出血性疾病**或出血倾向
6. **妊娠**（尤其前3个月致畸，最后3个月致胎儿出血）
7. **拟行区域麻醉/腰穿**
8. 对华法林或任何辅料过敏
9. **无法进行INR监测**的患者
10. **近期或即将行大手术**
11. 已知**蛋白C或蛋白S缺乏**（起始时血栓风险）

---

## 【注意事项】

1. **必须定期监测INR**，不可中断
2. **饮食中维生素K摄入应保持稳定**（不必完全禁食绿叶蔬菜，但要恒定）
3. 任何新加或停用的药物都应告知医生（大量药物有相互作用）
4. **避免突然改变饮食习惯**
5. 出现任何出血征象（黑便、血尿、持续鼻出血、异常瘀斑）应立即就医
6. 携带"正在服用华法林"的医疗警示卡
7. 外伤（尤其头部）后即使无明显出血也应就医检查
8. 手术/牙科操作前应告知正在使用华法林
9. **妊娠计划**：需在怀孕前转换为低分子肝素
10. 基因检测（CYP2C9/VKORC1）可指导起始剂量

## 【药理作用】

### 抗凝机制
- **维生素K拮抗剂**
- 抑制维生素K环氧化物还原酶（VKORC1）
- 阻止维生素K从环氧化物还原为氢醌型
- 使凝血因子II、VII、IX、X的γ-羧基化受阻
- 生成的凝血因子无凝血活性
- 同时影响抗凝蛋白C和蛋白S

### 起效时间
- 起效慢：需2-7天达到充分抗凝
- 原因：已有活化的凝血因子需要自然代谢消耗完毕
- 因子半衰期：II(60h) > IX(24h) > X(48h) > VII(4-6h)
- 因此，**初始可能需要重叠肝素**（桥接治疗）
