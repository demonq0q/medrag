# 苯磺酸氨氯地平片说明书

> **通用名**：苯磺酸氨氯地平片
> **英文名**：Amlodipine Besylate Tablets
> **ATC编码**：C08CA01
> **文档类型**：药品说明书综合整理

---

## 【药品名称】

- **通用名**：苯磺酸氨氯地平片
- **商品名**：络活喜（Norvasc）、安内真、压氏达
- **化学名**：(±)-2-[(2-氨基乙氧基)甲基]-4-(2-氯苯基)-1,4-二氢-6-甲基-3,5-吡啶二甲酸-3-乙酯-5-甲酯苯磺酸盐
- **分子式**：C₂₀H₂₅ClN₂O₅·C₆H₆O₃S
- **分子量**：567.1

---

## 【适应症】

1. **高血压**：单独或与其他降压药联合使用
2. **慢性稳定性心绞痛**
3. **变异型心绞痛**（Prinzmetal's心绞痛）
4. **冠心病**：经血管造影证实的冠心病患者，可降低心绞痛住院和冠脉血运重建的风险

---

## 【规格】

- 5mg / 10mg（以氨氯地平计）

---

## 【用法用量】

### 高血压
| 人群 | 起始剂量 | 最大剂量 |
|------|---------|---------|
| 一般成人 | 5mg，每日一次 | 10mg，每日一次 |
| 老年人/体弱者 | 2.5mg，每日一次 | 根据耐受逐步加量 |
| 肝功能不全 | 2.5mg，每日一次 | 慎用 |
| 儿童（6-17岁） | 2.5mg-5mg，每日一次 | 5mg（体重<35kg）/ 10mg |

### 心绞痛
- 成人：5-10mg，每日一次
- 大多数患者需10mg才能达到充分效果

### 服用说明
- 每日一次，固定时间服用
- 可与食物同服或空腹服用
- 漏服想起时可补服，但距下次<12h则跳过

---

## 【不良反应】

### 常见（>1%）

| 系统 | 不良反应 | 发生率 | 特点 |
|------|---------|--------|------|
| 血管 | **外周水肿（踝部/下肢水肿）** | 约3-8% | 剂量相关，女性更常见 |
| 神经 | 头痛 | 约3-7% | 多在治疗初期，可自行缓解 |
| 神经 | 头晕 | 约2-3% | — |
| 消化 | 恶心、腹痛 | 约1-2% | — |
| 全身 | 乏力 | 约2-3% | — |
| 心血管 | 面部潮红 | 约1-2% | 血管扩张所致 |
| 心血管 | 心悸 | 约1-2% | 反射性心动过速 |

### 偶见（0.1-1%）
- 体位性低血压
- 心律失常
- 呼吸困难
- 肌肉痉挛
- 尿频
- 性功能改变
- 牙龈增生

### 罕见（<0.1%）
- 严重低血压
- 晕厥
- 心肌梗死（极罕见，与基础疾病关系难区分）
- 肝炎、黄疸
-  Stevens-Johnson综合征
- 血管性水肿
- 震颤
- 味觉障碍

---

## 【禁忌症】

1. 对二氢吡啶类钙通道阻滞剂**过敏**
2. **严重低血压**（收缩压<90mmHg）
3. **心源性休克**
4. **严重主动脉瓣狭窄**
5. **不稳定型心绞痛**（相对禁忌，证据不足）
6. 妊娠（动物实验有致畸性，人类数据不足）
7. 哺乳期（可分泌入乳汁）

---

## 【注意事项】

1. **肝功能不全**：氨氯地平半衰期延长（可达56h），应使用低剂量并密切监测
2. **心力衰竭**：心衰患者使用CCB需谨慎（虽然氨氯地平PRAISE试验显示安全性较好）
3. **停药**：突然停药不会引起血压反弹（与β阻滞剂不同）
4. **老年人**：清除率降低，起始剂量宜低
5. **肾功能不全**：正常透析不影响清除率，无需调整剂量
6. **驾驶/操作机械**：可能出现头晕、乏力，需注意
7. **外周水肿**的鉴别：需与心衰所致水肿鉴别
8. 与其他降压药合用时降压效果叠加，需监测血压

## 【药物相互作用】

| 合并用药 | 相互作用 | 临床意义 |
|---------|---------|---------|
| **辛伐他汀** | 氨氯地平使辛伐他汀暴露量增加 | 辛伐他汀日剂量不超过20mg |
| **环孢素** | 可能增加环孢素血药浓度 | 监测环孢素浓度 |
| **他克莫司** | 可能增加他克莫司血药浓度 | 监测浓度 |
| **西地那非** | 协同降压 | 注意低血压 |
| **CYP3A4强抑制剂**（酮康唑等） | 增加氨氯地平血药浓度 | 监测血压，可能需减量 |
| **CYP3A4诱导剂**（利福平等） | 降低氨氯地平血药浓度 | 可能需增量 |
| **葡萄柚汁** | 轻度抑制CYP3A4 | 影响较小，适量饮用 |
| **β受体阻滞剂** | 可联合使用降压 | 安全联合，但心功能需监测 |
| **地高辛** | 不影响地高辛水平 | 无明显相互作用 |

## 【药理作用】

### 降压机制
- **二氢吡啶类钙通道阻滞剂（CCB）**
- 选择性抑制血管平滑肌L型钙通道
- 阻止钙离子内流
- **主要作用于外周动脉**→血管扩张→降低外周阻力→降压
- 对心脏传导和收缩的影响较小（与维拉帕米/地尔硫卓不同）
- 对冠脉血管也有扩张作用→改善心肌供血

### 药理学特点
- 起效缓慢（避免反射性交感激活）
- 作用持久（24h平稳降压）
- 无短效CCB的血压波动问题
- 不影响心率（或轻度减慢）
- 不影响心脏传导系统

## 【药代动力学】

| 参数 | 数值 |
|------|------|
| 口服生物利用度 | 64-90% |
| 达峰时间 | 6-12h |
| 蛋白结合率 | 93% |
| 分布容积 | 21 L/kg |
| 代谢 | 肝脏CYP3A4 |
| 半衰期 | **35-50h**（长效，一日一次即可） |
| 稳态时间 | 7-8天 |
| 排泄 | 肾脏（代谢产物），10%原形 |
| 食物影响 | 不影响吸收 |

**特殊人群**：
- 老年人：清除率降低，半衰期延长
- 肝功能不全：半衰期可延长至56h
- 肾功能不全：不影响药代动力学
