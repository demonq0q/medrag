# 中国高血压防治指南（2024年版）核心要点

> **发布机构**：中国高血压联盟、国家心血管病中心
> **发布年份**：2024年
> **文档类型**：临床实践指南
> **适用人群**：≥18岁成人

---

## 一、中国高血压流行病学

| 指标 | 数值 |
|------|------|
| 中国成人高血压患病率 | 27.5% |
| 高血压患者总数 | 约2.45亿 |
| 知晓率 | 51.6% |
| 治疗率 | 45.8% |
| 控制率 | 16.8% |

### 心血管风险分层

| 其他危险因素/疾病 | 1级高血压 | 2级高血压 | 3级高血压 |
|------------------|----------|----------|----------|
| 无其他RF | 低危 | 中危 | 高危 |
| 1-2个RF | 中危 | 中-高危 | 很高危 |
| ≥3个RF或靶器官损害 | 高危 | 高危 | 很高危 |
| 合并临床并发症/CKD≥3期/糖尿病 | 很高危 | 很高危 | 很高危 |

**危险因素包括**：年龄（男≥55, 女≥65）、吸烟、糖耐量异常、血脂异常、腹型肥胖、早发心血管病家族史

## 二、血压测量与诊断标准

### 2.1 血压诊断标准

| 测量方式 | 诊断阈值 |
|---------|---------|
| 诊室血压 | ≥140/90 mmHg |
| 家庭自测血压 | ≥135/85 mmHg |
| 24h动态血压-全天 | ≥130/80 mmHg |
| 24h动态血压-白天 | ≥135/85 mmHg |
| 24h动态血压-夜间 | ≥120/70 mmHg |

### 2.2 血压分级

| 分级 | 收缩压(mmHg) | 舒张压(mmHg) |
|------|-------------|-------------|
| 正常血压 | <120 | 且 <80 |
| 正常高值 | 120-139 | 和/或 80-89 |
| 1级高血压 | 140-159 | 和/或 90-99 |
| 2级高血压 | 160-179 | 和/或 100-109 |
| 3级高血压 | ≥180 | 和/或 ≥110 |
| 单纯收缩期高血压 | ≥140 | 且 <90 |

### 2.3 正确测量方法
1. 测量前30分钟避免吸烟、咖啡、运动
2. 排空膀胱
3. 安静坐位休息5分钟
4. 背靠椅背，双脚平放地面
5. 袖带与心脏同高
6. 每次测量2-3次，取平均值
7. 首次就诊应测双上臂血压

## 三、降压治疗目标

### 3.1 一般目标

| 人群 | 目标血压 | 证据等级 |
|------|---------|---------|
| 一般高血压患者 | <140/90 mmHg | A |
| 合并糖尿病 | <130/80 mmHg | A |
| 合并冠心病 | <130/80 mmHg | B |
| 合并CKD | <130/80 mmHg | A |
| 合并心力衰竭 | <130/80 mmHg | A |
| 老年（65-79岁） | <140/90 mmHg（可耐受则<130/80） | A |
| 高龄（≥80岁） | <150/90 mmHg（可耐受则<140/90） | B |

### 3.2 SPRINT研究启示
- 强化降压（收缩压<120mmHg）可进一步降低心血管事件和全因死亡
- 但需权衡不良反应（低血压、晕厥、肾功能恶化）

## 四、生活方式干预

### 4.1 生活方式干预措施及降压效果

| 措施 | 推荐 | 预期降压幅度 |
|------|------|------------|
| **减盐** | 每日食盐<5g（钠<2g） | 收缩压降低5-6mmHg |
| **减重** | BMI<24, 腰围男<90cm女<85cm | 每减10kg降收缩压5-20mmHg |
| **DASH饮食** | 多蔬菜水果、低脂乳制品、少红肉 | 收缩压降低8-14mmHg |
| **限酒** | 男酒精<25g/d, 女<15g/d | 收缩压降低2-4mmHg |
| **运动** | 每周≥150分钟中等强度有氧运动 | 收缩压降低4-9mmHg |
| **戒烟** | 完全戒烟 | 降低总体心血管风险 |
| **补钾** | 每日3.5-4.7g（肾功能正常者） | 收缩压降低2-4mmHg |

## 五、降压药物选择

### 5.1 五大类降压药

| 类别 | 代表药物 | 降压机制 | 适用人群 | 禁忌 |
|------|---------|---------|---------|------|
| **CCB**（钙通道阻滞剂） | 氨氯地平、硝苯地平控释片 | 扩张血管 | 老年、单纯收缩期高血压、卒中预防 | 快速心律失常（非DHP） |
| **ACEI**（普利类） | 卡托普利、依那普利、培哚普利 | 抑制RAS系统 | 糖尿病、CKD、心衰、心梗后 | 妊娠、双侧肾动脉狭窄、高钾 |
| **ARB**（沙坦类） | 缬沙坦、厄贝沙坦、氯沙坦 | 阻断AT1受体 | 同ACEI，ACEI不耐受时替代 | 妊娠、双侧肾动脉狭窄 |
| **利尿剂** | 氢氯噻嗪、吲达帕胺 | 利钠排水 | 老年、盐敏感、联合用药 | 痛风（噻嗪类） |
| **β受体阻滞剂** | 美托洛尔、比索洛尔 | 减慢心率/降心输出量 | 合并冠心病、心衰、快速心率 | 严重心动过缓、哮喘 |

### 5.2 用药原则

**单药起始**适用人群：
- 1级高血压且低-中危
- 老年虚弱患者

**联合起始**适用人群：
- 2级以上高血压
- 高于目标值≥20/10mmHg
- 高危/很高危患者

### 5.3 推荐联合方案

| 优先推荐 | 可选联合 | 不推荐 |
|---------|---------|--------|
| ACEI/ARB + CCB | CCB + 利尿剂 | ACEI + ARB |
| ACEI/ARB + 利尿剂 | β阻滞剂 + CCB | — |
| CCB + β阻滞剂（特殊适应证） | — | — |

**单片复方制剂（SPC）推荐**：
- ACEI/ARB + CCB 的 SPC
- ACEI/ARB + 利尿剂 的 SPC
- 提高依从性，是优选的联合用药方式

## 六、特殊类型高血压

### 6.1 老年高血压
- 起始药物治疗从低剂量开始
- 目标值可适度放宽（<150/90，耐受则<140/90）
- 注意体位性低血压
- 优选CCB、利尿剂、ACEI/ARB

### 6.2 妊娠高血压
- **安全药物**：拉贝洛尔、硝苯地平、甲基多巴
- **禁用药物**：ACEI、ARB、直接肾素抑制剂（致畸）
- 子痫前期预防：高危孕妇可用小剂量阿司匹林

### 6.3 难治性高血压
- 定义：3种降压药（含利尿剂）足量治疗仍未达标
- 处理：确认依从性 → 排除继发性 → 加用螺内酯 → 考虑其他方案

### 6.4 高血压急症
- 定义：血压严重升高（通常>180/120）伴急性靶器官损害
- 处理原则：
  - 静脉降压（硝普钠、拉贝洛尔、乌拉地尔）
  - 1小时内MAP降低不超过25%
  - 2-6h降至约160/100-110
  - 24-48h逐渐降至正常
  - 例外：急性主动脉夹层→收缩压迅速降至<120

## 七、继发性高血压筛查指征

以下情况应怀疑继发性高血压并进一步检查：

| 线索 | 可能病因 | 筛查方法 |
|------|---------|---------|
| 年轻发病（<30岁）且无家族史 | 肾血管性 | 肾动脉超声/CTA |
| 突发重度高血压 | 嗜铬细胞瘤 | 血/尿儿茶酚胺 |
| 低钾血症 | 原发性醛固酮增多症 | 醛固酮/肾素比值 |
| 满月脸、水牛背 | 库欣综合征 | 24h尿游离皮质醇 |
| 打鼾、肥胖、嗜睡 | 阻塞性睡眠呼吸暂停 | 多导睡眠图 |
| 肾脏缩小或双侧不对称 | 肾实质性疾病 | 肾脏超声/CT |

## 八、关键推荐意见汇总

| 编号 | 推荐意见 | 证据等级 |
|------|---------|---------|
| REC-01 | 诊室血压≥140/90mmHg可诊断高血压（非同日3次） | A |
| REC-02 | 一般患者降压目标<140/90，耐受可降至<130/80 | A |
| REC-03 | 合并糖尿病/CKD/冠心病目标<130/80 | A |
| REC-04 | 限盐<5g/天是高血压管理的基础措施 | A |
| REC-05 | ACEI/ARB+CCB或ACEI/ARB+利尿剂是优先联合方案 | A |
| REC-06 | 推荐使用单片复方制剂提高依从性 | A |
| REC-07 | 妊娠高血压禁用ACEI/ARB | A |
| REC-08 | 高血压急症应静脉降压，1h内MAP降低不超25% | B |
| REC-09 | 年轻发病/难治性/低钾血症应筛查继发性高血压 | B |
| REC-10 | β阻滞剂合并哮喘时禁用 | A |
