# 中国糖尿病防治指南（2024版）核心要点

> **发布机构**：中华医学会糖尿病学分会
> **发布年份**：2024年
> **文档类型**：临床实践指南
> **证据等级说明**：A=多项RCT, B=单项RCT/大型队列, C=小样本/病例对照, D=专家共识

---

## 一、中国糖尿病流行病学现状

### 1.1 患病率数据

| 指标 | 数值 | 数据来源 |
|------|------|---------|
| 中国成人糖尿病患病率 | 11.2% | 2015-2017年全国调查 |
| 糖尿病前期患病率 | 35.2% | 同上 |
| 糖尿病患者总数 | 约1.4亿 | 估算值 |
| 2型糖尿病占比 | >90% | — |
| 知晓率 | 36.5% | — |
| 治疗率 | 32.9% | — |
| 控制率 | 49.2% | — |

### 1.2 危险因素
- 超重/肥胖（BMI≥24 kg/m²）
- 一级亲属有糖尿病史
- 年龄≥40岁
- 有妊娠期糖尿病史的女性
- 高血压（血压≥140/90mmHg或正在接受降压治疗）
- 血脂异常（HDL-C≤0.90mmol/L和/或TG≥2.22mmol/L）
- 心血管疾病史
- 有一过性类固醇糖尿病史者
- 多囊卵巢综合征（PCOS）患者
- 长期接受抗精神病药物和/或抗抑郁药物治疗者

## 二、糖尿病诊断标准

### 2.1 血糖诊断标准

| 诊断条件 | 静脉血浆葡萄糖 |
|---------|-------------|
| 典型糖尿病症状 + 随机血糖 | ≥11.1 mmol/L |
| 或 空腹血糖（FPG） | ≥7.0 mmol/L |
| 或 OGTT 2h血糖 | ≥11.1 mmol/L |
| 或 HbA1c（标准化检测） | ≥6.5% |

**注意事项**：
- 无典型症状者需**非同日复查**确认
- 空腹定义：至少8小时未摄入热量
- HbA1c检测须采用NGSP/IFCC标准化方法
- 急性感染、创伤等应激状态下血糖可暂时升高，需在应激消除后复查

### 2.2 糖尿病前期诊断

| 类型 | 血糖值 |
|------|--------|
| 空腹血糖受损（IFG） | FPG 6.1-6.9 mmol/L 且 OGTT 2h <7.8 |
| 糖耐量减低（IGT） | FPG <7.0 且 OGTT 2h 7.8-11.0 mmol/L |

## 三、2型糖尿病综合控制目标

### 3.1 控制目标（一般成人）

| 指标 | 目标值 | 证据等级 |
|------|--------|---------|
| HbA1c | <7.0% | A |
| 空腹血糖 | 4.4-7.0 mmol/L | A |
| 非空腹血糖 | <10.0 mmol/L | B |
| 血压 | <130/80 mmHg | A |
| TC | <4.5 mmol/L | B |
| LDL-C（未合并ASCVD） | <2.6 mmol/L | A |
| LDL-C（合并ASCVD） | <1.8 mmol/L | A |
| TG | <1.7 mmol/L | B |
| HDL-C（男） | >1.0 mmol/L | B |
| HDL-C（女） | >1.3 mmol/L | B |
| BMI | <24 kg/m² | B |

### 3.2 个体化控制目标

**放宽目标（HbA1c <8.0%）适用人群**：
- 病程长、有严重低血糖史
- 预期寿命有限
- 严重并发症
- 儿童/老年人
- 难治性高血压

**严格目标（HbA1c <6.5%）适用人群**：
- 病程短
- 预期寿命长
- 无严重心血管并发症
- 仅用生活方式或二甲双胍治疗即可达标
- 无低血糖风险

## 四、2型糖尿病药物治疗路径

### 4.1 一线治疗

**推荐**：生活方式干预 + **二甲双胍**（证据等级：A）

**二甲双胍用药要点**：
- 起始剂量：500mg，每日1-2次
- 逐渐加量：每1-2周增加500mg
- 目标剂量：1000-2000mg/天
- 普通片随餐或餐后服用（减少胃肠道反应）
- 缓释片随晚餐服用，每日一次
- eGFR <45 ml/min 时禁用
- 长期使用需监测维生素B12

### 4.2 二线治疗（二甲双胍单药3个月HbA1c不达标）

**合并ASCVD或高危因素**：
- 首选加用 **GLP-1受体激动剂**（如利拉鲁肽、司美格鲁肽）或 **SGLT2抑制剂**（如达格列净、恩格列净）
- 证据等级：A
- 无论HbA1c是否达标，均推荐使用具有心肾保护证据的药物

**合并心衰（HF）或CKD**：
- 首选 **SGLT2抑制剂**
- 证据等级：A
- 达格列净 eGFR≥25 可用；恩格列净 eGFR≥20 可用

**无明显ASCVD/心衰/CKD**：
- 可选：GLP-1RA、SGLT2i、DPP-4i、TZD、磺脲类
- 选择依据：低血糖风险、体重影响、费用、患者偏好

### 4.3 三联治疗

二联治疗3个月HbA1c仍不达标 → 加用第三种口服药或GLP-1RA

### 4.4 胰岛素治疗

**启动胰岛素指征**：
- HbA1c ≥ 9.0% 且伴有明显高血糖症状
- 口服联合治疗3-6个月HbA1c仍不达标
- 存在明显分解代谢表现（体重快速下降）
- 鉴别诊断困难（难以分型）

**基础胰岛素起始方案**：
- 起始剂量：0.1-0.3 U·kg⁻¹·d⁻¹
- 从每日一次基础胰岛素开始
- 根据空腹血糖每3-5天调整2-4U
- 空腹血糖目标：4.4-7.0 mmol/L

## 五、常用口服降糖药物对比

### 5.1 各类药物汇总表

| 类别 | 代表药物 | 降HbA1c | 低血糖风险 | 体重影响 | 心血管获益 | 主要不良反应 |
|------|---------|---------|-----------|---------|-----------|------------|
| 双胍类 | 二甲双胍 | 1.0-1.5% | 低 | 减轻/中性 | 可能 | 胃肠道反应 |
| SGLT2i | 达格列净/恩格列净 | 0.5-1.0% | 低 | 减轻 | ✅ 明确 | 泌尿生殖系感染、DKA |
| GLP-1RA | 利拉鲁肽/司美格鲁肽 | 1.0-1.5% | 低 | 明显减轻 | ✅ 明确 | 胃肠道反应 |
| DPP-4i | 西格列汀/利格列汀 | 0.5-0.8% | 低 | 中性 | 中性 | 鼻咽炎、头痛 |
| 磺脲类 | 格列美脲/格列齐特 | 1.0-1.5% | 较高 | 增加 | 中性 | 低血糖、体重增加 |
| 格列奈类 | 瑞格列奈 | 0.5-1.0% | 中等 | 增加/中性 | 中性 | 低血糖 |
| α-糖苷酶抑制剂 | 阿卡波糖 | 0.5-0.8% | 低 | 中性 | 可能 | 腹胀、排气增多 |
| TZD | 吡格列酮 | 1.0-1.5% | 低 | 增加 | 可能 | 水肿、心衰风险、骨折 |

### 5.2 特殊人群用药选择

| 特殊情况 | 优选药物 | 避免药物 |
|---------|---------|---------|
| 合并ASCVD | GLP-1RA / SGLT2i | — |
| 合并心衰 | SGLT2i | TZD |
| 合并CKD(eGFR≥25) | SGLT2i / 利格列汀 | 二甲双胍(eGFR<30) |
| 需减重 | GLP-1RA / SGLT2i | 磺脲类、TZD、胰岛素 |
| 低血糖风险高 | DPP-4i / GLP-1RA / SGLT2i | 磺脲类、格列奈类 |
| 经济受限 | 磺脲类 / 二甲双胍 | — |
| 老年人 | DPP-4i / SGLT2i | 长效磺脲类 |

## 六、低血糖管理

### 6.1 低血糖分级

| 级别 | 血糖值 | 表现 | 处理 |
|------|--------|------|------|
| 1级（警觉值） | <3.9 mmol/L | 心悸、手抖、出汗、饥饿 | 口服15-20g葡萄糖 |
| 2级（临床显著） | <3.0 mmol/L | 意识模糊、行为异常 | 需他人协助处理 |
| 3级（严重） | 无阈值 | 意识丧失、抽搐、昏迷 | 静脉注射50%葡萄糖或肌注胰高血糖素 |

### 6.2 低血糖处理原则（"15-15规则"）
1. 摄入15g快速碳水化合物（如葡萄糖片3-4片、含糖饮料150mL）
2. 等待15分钟
3. 复测血糖
4. 如仍<3.9 mmol/L，重复上述步骤
5. 血糖恢复后进食含淀粉食物维持

## 七、糖尿病慢性并发症筛查

### 7.1 筛查时间表

| 并发症 | 筛查方法 | 筛查频率 | 起始时间 |
|--------|---------|---------|---------|
| 糖尿病视网膜病变 | 眼底检查（散瞳） | 每年1次 | 诊断时（2型） |
| 糖尿病肾病 | UACR + eGFR | 每年1次 | 诊断时 |
| 糖尿病周围神经病变 | 10g尼龙丝+音叉+针刺 | 每年1次 | 诊断时 |
| 糖尿病足 | 足部检查（视诊+触诊+感觉） | 每次就诊 | 诊断时 |
| 心血管疾病 | 心电图、血脂 | 每年1次 | 诊断时 |

### 7.2 糖尿病肾病诊断标准
- **白蛋白尿**：UACR ≥ 30 mg/g（3次中有2次以上）
- **eGFR下降**：<60 mL/min/1.73m²
- 两者任一项持续>3个月即可诊断

### 7.3 糖尿病肾病治疗
- **ACEI/ARB**：合并高血压或UACR≥30mg/g时使用（证据A）
- **SGLT2抑制剂**：eGFR≥25时推荐使用（证据A）
- **非奈利酮**：T2DM合并CKD、已用最大剂量ACEI/ARB、UACR仍≥30mg/g（证据A）
- **蛋白摄入**：0.8 g·kg⁻¹·d⁻¹

## 八、2型糖尿病患者的体重管理

### 8.1 体重管理目标
- BMI ≥ 24：减重 ≥ 5%（初始目标）
- 理想减重：≥ 10-15%（可获得糖尿病缓解机会）

### 8.2 减重药物选择
| 药物 | 减重幅度 | 降糖效果 |
|------|---------|---------|
| 司美格鲁肽 2.4mg | 约15% | HbA1c降低1.5%+ |
| 替尔泊肽 | 约20% | HbA1c降低2.0%+ |
| 利拉鲁肽 3.0mg | 约5-8% | HbA1c降低1.0%+ |

## 九、关键推荐意见汇总

| 编号 | 推荐意见 | 证据等级 |
|------|---------|---------|
| REC-01 | 二甲双胍是2型糖尿病一线首选降糖药物 | A |
| REC-02 | 合并ASCVD患者应优先选用有心血管获益证据的GLP-1RA或SGLT2i | A |
| REC-03 | 合并心衰或CKD的患者优先选用SGLT2i | A |
| REC-04 | HbA1c≥9%且有明显高血糖症状时应考虑起始胰岛素治疗 | B |
| REC-05 | 所有2型糖尿病患者诊断时应进行眼底检查 | B |
| REC-06 | 合并白蛋白尿的CKD患者应使用ACEI/ARB | A |
| REC-07 | 基础胰岛素起始剂量0.1-0.3 U/kg/d | B |
| REC-08 | 二甲双胍eGFR<45时禁用 | A |
| REC-09 | SGLT2i用于心衰患者可降低心衰住院风险 | A |
