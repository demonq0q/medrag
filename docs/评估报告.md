# 小荷 MedRAG 评估报告

## 1. 评估配置

- 数据集：`med-rag-data/evaluation/test_set.json`
- 当前规模：50 条题目，覆盖疾病基础、用药指导、检查解读、药物相互作用、饮食生活、特殊人群和急救常识。
- 生成模式：`template`，不依赖外部 LLM Key，便于 CI 和离线复现。
- 执行命令：`python scripts/evaluate.py`

## 2. 基线结果（2026-08-08）

| 指标 | 结果 |
| --- | ---: |
| 答案生成率 | 100% |
| 引用覆盖率 | 94% |
| 来源命中率 | 56% |
| 关键实体命中率 | 98% |
| 平均延迟 | 29.13 ms |
| P50 延迟 | 11.75 ms |
| P95 延迟 | 27.05 ms |

来源命中率较低的主要原因是原始评估集中的 `ground_truth_docs` 同时使用 `faq_###`、`DDI_###`、`LAB_###` 和自然语言文档名；系统已经统一建立 `source_id`，下一步应将评估集来源全部注册到同一映射表后再比较。

## 4. 关键验收用例

- `华法林和阿司匹林能否同时服用`：返回 `high/high_risk_review`，首条引用为直接相互作用证据。
- `扑热息痛能治疗什么`：标准化为 `对乙酰氨基酚能治疗什么`。
- 血糖参考范围问题：返回参考范围、单位、样本类型、临床意义和影响因素。
- 不存在的药物剂量：返回 `blocked_no_evidence`，不猜测剂量且无伪造引用。
- PDF 证据：Chunk 保存页码和章节字段。

## 5. 解释和限制

该报告是离线模板模式的工程基线，不代表临床效果或真实世界诊断准确率。接入 Embedding、Reranker 和审核后的 LLM 后，应重新评估 Recall@K、MRR、NDCG、引用精确率、拒答召回率和人工医学质量评分。
