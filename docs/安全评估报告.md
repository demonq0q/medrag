# 小荷 MedRAG 安全评估报告

## 1. 安全边界

系统是医学知识辅助工具，不替代医生诊断、处方或急诊服务。回答只允许引用本地知识库，不能把模型自由发挥当作医疗事实。

## 2. 已实现控制

| 风险 | 控制 |
| --- | --- |
| 急症延误 | 识别胸痛、呼吸困难、意识障碍、大出血、抽搐等关键词，返回立即就医提示 |
| 药物相互作用 | 结构化药物对查询优先，严重/禁忌级别提升为高风险审核 |
| 无来源剂量 | 审核回答中的剂量模式，高风险问题必须存在真实证据 |
| 幻觉 | 无医学实体或无检索证据时 fail-closed，清空引用并拒绝猜测 |
| 引用失效 | 引用直接绑定 `ChunkRecord`，保留 `source_id`、section、page_number |
| 数据污染 | 数据校验器检查 JSON、重复 ID、数量声明和 SHA-256 内容指纹 |
| 隐私 | 默认不写入原始个人身份信息；生产环境应配置日志脱敏、API Key 和限流 |

## 3. 已验证场景

- 严重相互作用能够返回风险、机制、临床影响、处理建议和监测项。
- 未知药品/剂量被拒答，不输出虚构来源。
- 每个响应引用 ID 都能在检索结果中找到对应 Chunk。
- API 无 LLM Key 仍能运行模板模式、安全审核和健康检查。
- Docker 容器只把生成目录挂载为 volume，原始数据镜像内保持只读使用。

## 4. 剩余风险

1. 当前模板生成器不等于经过临床验证的医疗模型；接入外部 LLM 前必须增加输出结构校验和人工抽检。
2. 原始数据的权威性、时效性和版权需要业务方持续审查，系统暂不自动判断医学指南是否最新。
3. 生产环境还应增加用户认证、审计日志、请求限流、密钥管理、数据删除策略和安全告警。
4. 评估集目前为 50 条，需扩充并经医学专家标注后才能用于正式质量门禁。
