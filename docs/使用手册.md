# 小荷 MedRAG 使用手册

## 1. 公网地址

- Web：<https://medrag.986889.xyz>
- 健康检查：<https://medrag.986889.xyz/health>
- OpenAPI：启动 API 后访问 `/docs`，公网当前由前端统一反代，调试时可访问 API 容器映射端口。

## 2. 本地启动

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
python -m medrag.cli validate
python -m medrag.cli build
uvicorn medrag.app:app --host 0.0.0.0 --port 8000
```

另开终端启动前端：

```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0
```

## 3. Docker 启动

Compose 会为 API 和 Web 的宿主机映射分配随机端口：

```bash
docker compose up -d --build
docker compose ps
docker compose port api 8000
docker compose port web 80
```

当前服务器的 Web 随机端口可通过以下命令读取，不能硬编码：

```bash
docker compose port web 80
```

首次启动时 API 容器会在持久化 volume 中构建 SQLite 知识库。生产环境建议复制 `.env.example` 为 `.env`，设置 API Key、CORS 和 LLM Provider。

## 4. Caddy 反代

宿主机已经运行 Caddy 时执行：

```bash
scripts/configure_caddy_host.sh
```

脚本会读取 Web 随机端口、备份 `/etc/caddy/Caddyfile`、校验配置并 reload Caddy。当前服务器旧版 Buildx 会自动使用 legacy builder；升级 Buildx 后可恢复 Compose 原生构建。

## 5. API 示例

```bash
curl -sS https://medrag.986889.xyz/api/v1/query \
  -H 'content-type: application/json' \
  -d '{"question":"华法林和阿司匹林能否同时服用"}'
```

常用接口：

- `GET /health`
- `GET /api/v1/metrics`
- `POST /api/v1/query`
- `GET /api/v1/conversations`
- `GET /api/v1/interactions?drug_a=华法林&drug_b=阿司匹林`
- `POST /api/v1/documents/preview`

## 6. 评估和测试

```bash
pytest tests -q
ruff check src/medrag scripts tests
python scripts/evaluate.py
npm --prefix frontend run build
```

评估结果写入 `artifacts/reports/evaluation.json`，该目录是生成目录，不进入 Git。
